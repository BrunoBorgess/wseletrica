# WS Elétrica — Site (Next.js + Tailwind)

## Rodar localmente
```
npm install
npm run dev
```
Acesse http://localhost:3000

## Estrutura
- app/page.tsx — monta a página
- app/components/* — Header, Hero, Services, About, Projects, CTA, Footer
- tailwind.config.ts — cores (navy/volt) e fontes

## Simplificações feitas em relação ao print original
- Removida a galeria de fotos de projetos (sem fotos reais disponíveis) e a seção de depoimentos/FAQ, para focar no essencial e ganhar tempo.
- "Sobre" e "Como trabalhamos" foram unidos em uma única seção.
- Paleta trocada para navy + azul elétrico (volt), mais consistente com a logo e mais fácil de escalar.
- Troque os placeholders de imagem (bloco navy no Hero) por fotos reais quando tiver.
